# Calculadora Simples em Python

## 📌 Sobre o Projeto

Este é um projeto simples de uma calculadora desenvolvida em Python para praticar conceitos básicos da linguagem, como:

* Entrada de dados (`input`)
* Estruturas condicionais (`if`, `elif` e `else`)
* Operadores matemáticos
* Tratamento de erros simples
* Uso de variáveis

A calculadora permite realizar as quatro operações matemáticas básicas:

* Soma (+)
* Subtração (-)
* Multiplicação (*)
* Divisão (/)

Além disso, o programa verifica se o usuário está tentando dividir um número por zero e exibe uma mensagem de erro apropriada.

## 💻 Exemplo de Uso

```text
=== Calculadora Simples ===

Olá, vamos calcular

Digite um Numero: 10
Digite mais um Numero: 5

Escolha a Operação:
+ Para Soma
- Para Menos
* Para Multiplicação
/ Para Divisão

Digite a operação que você deseja fazer: +

10 + 5 = 15
```
